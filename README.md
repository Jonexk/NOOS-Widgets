## 📱 About The Project

**NOOS Widgets** is a carefully curated collection of custom presets designed for users who appreciate minimalism, typography, and clean user interfaces. Every single widget is crafted to blend seamlessly with dynamic wallpapers and dark/light system setups.

* **Total Presets:** 40 Widgets
* **Aesthetic:** Dot-Matrix & Nothing OS UI
* **Color System:** Adaptive (Auto-switches between Light & Dark themes)
* **Compatibility:** Universal support for high-resolution displays and custom launchers

## ⚡ Prerequisites

To use **NOOS Widgets**, make sure you have the following installed on your device:

1. **KWGT Kustom Widget Maker** (Base App)
2. **KWGT Pro Key** *(Required by Kustom to import third-party APK/preset files)*
3. A custom launcher that supports widget resizing (e.g., Nova Launcher, Lawnchair, Smart Launcher, Nothing Launcher).

---

## 🚀 Installation Guide

1. Head over to the **[Releases](../../releases)** tab on this repository.
2. Download the latest **`NOOS_Widgets_V1.apk`** file.
3. Install the APK on your Android device (ensure "Install from unknown sources" is enabled if prompted).
4. Go to your home screen, long-press, and select **Widgets** -> **KWGT**.
5. Tap the empty widget box, open the **NOOS Widgets** tab in the installed packs section, and select your preset.
6. Hit the **Save** icon at the top right, and enjoy your new setup!
